This
[Cybersecurity Awareness Month](https://en.wikipedia.org/wiki/Cyber_Security_Awareness_Month),
I made seven Python releases, when two were originally planned for October.

Altogether, we made 16 Python releases, when five were originally planned. Of the extra
releases, only 3.15.0rc3 was not a security release.
